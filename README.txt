WORLD.EXE 상세 페이지 업데이트

업로드할 파일: app.js, style.css, detail.html, .pages.yml
GitHub 저장소 archive의 최상위(root)에 네 파일을 올리고 기존 파일 덮어쓰기(Commit changes).
중요: data/ 폴더 및 기존 JSON 파일은 업로드하거나 덮어쓰지 마세요. 이미 Pages CMS에서 수정한 작품 데이터가 유지되어야 합니다.

작품/캐릭터 카드 클릭 → detail.html?type=works&id=w1 등의 상세 페이지 이동.
Pages CMS에서 작품 상세 소개(detail), 외부 링크(link), 캐릭터 성격/외형 등을 추가 입력할 수 있습니다.
기존 데이터에 새 필드가 없어도 정상 표시됩니다.
관련 캐릭터는 workId(예: w1)로 연결. 기존 항목은 캐릭터의 소속 작품(category)과 작품 제목(title)이 같으면 자동 연결.
프로필은 기존 profile.html에서 자세한 자기소개(bio), 활동 링크(links) 추가 표시.

주의: 이 업데이트는 기존 홈페이지의 디자인을 최대한 유지합니다.
