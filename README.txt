WORLD.EXE 숨겨진 편집 주소 버전

공개 홈페이지 상단에서 '편집' 링크를 제거했습니다.
관리자 페이지는 admin.html 파일로 그대로 존재합니다.

중요: 링크를 숨겨도 admin.html 접근은 차단되지 않습니다. URL을 아는 누구나 열 수 있습니다.
또한 편집 데이터는 브라우저 localStorage에 저장되어 다른 방문자에게 자동 게시되지 않습니다.
실제 공개 사이트를 수정하려면 별도 배포/내보내기 기능이 필요합니다.

공개 사이트에 admin.html을 업로드하지 않고 컴퓨터에만 보관하는 편이 더 안전합니다.
